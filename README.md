# Retail Sales Analytics Dashboard

## Project Overview

The Retail Sales Analytics Dashboard is an end-to-end Business Intelligence project developed using Microsoft Excel, SQL, and Power BI. The project focuses on transforming raw retail sales data into meaningful business insights through data cleaning, modeling, analysis, and interactive visualizations.

## Tools Used

* Microsoft Excel
* SQL (MySQL)
* Power BI

## Objective

The primary objective of this project was to analyze retail sales data and create an interactive dashboard that supports data-driven business decision-making. The dashboard enables stakeholders to monitor key performance indicators, identify sales trends, evaluate product performance, and analyze regional business growth.

## Work Performed

### Data Preparation in Excel

* Cleaned and structured customer, product, order, and region datasets.
* Standardized data formats and verified data quality.
* Organized datasets for efficient integration with SQL and Power BI.

### SQL Data Analysis

* Created and managed database tables.
* Wrote SQL queries to extract, filter, and analyze sales data.
* Generated insights related to sales performance, customers, products, and regions.

### Data Modeling in Power BI

* Imported datasets into Power BI.
* Created relationships between Customers, Products, Orders, and Regions tables.
* Designed a data model to support reporting and analytics.

### KPI Development

Developed key performance indicators including:

* Total Sales
* Total Profit
* Orders Count
* Top Performing Products
* Regional Performance Analysis

### Dashboard Development

* Built an interactive Power BI dashboard with filters and slicers.
* Created visualizations to monitor sales trends and business performance.
* Enabled users to explore insights across products, customers, and regions.

## Skills Demonstrated

Successfully developed a Retail Sales Analytics Dashboard that converts raw sales data into actionable business insights.
